## Objetivo

- comunicar proposta e valor do projeto em contexto de demo,
- servir de apoio para apresentacoes academicas,
- manter narrativa visual separada da aplicacao principal.

## Para que serve

- Demonstrar o projeto para apresentacoes, contexto academico e divulgacao.
- Comunicar objetivos, proposta e arquitetura de forma visual.

## Quando e necessario

- Necessario para demos e comunicacao externa.
- Opcional para desenvolvimento tecnico do produto principal.

## Execucao simples

- Abrir `website promocional/index.html` no browser.

## Manutencao recomendada

- manter conteudo alinhado com estado real do produto,
- evitar duplicar detalhes tecnicos profundos (usar `docs/readmes` para isso),
- tratar esta pagina como material de comunicacao, nao como fonte de contrato tecnico.
